1.critic网络结构改成三个输出头的
输入：state + action + preference
        ↓
共享层 fc1 / fc2
        ↓
adv_head  -> Q_adv
coop_head -> Q_coop
obj_head  -> Q_obj
        ↓
拼接输出 [Q_adv, Q_coop, Q_obj]

2. Actor 怎么同时兼顾三个目标？
Actor 的核心不是“选一个目标”，而是**根据偏好向量 `w` 做标量化优化**。
最基本的 Actor loss 是：
```
actions = actor(batch.states, batch.prefs)
q_vec = critic(batch.states, actions, batch.prefs)

weighted_q = (q_vec * batch.prefs).sum(dim=-1)
actor_loss = -weighted_q.mean()
```

也就是：

```
最大化：
w_adv  * Q_adv
+ w_coop * Q_coop
+ w_obj  * Q_obj
```

这个方法叫：

```
weighted-sum scalarization
```

它是最常用、最稳定的多目标方法之一。

如果你只固定一个权重：

```
w = [0.2, 0.1, 0.7]
```

那 Actor 只会学一个偏好下的策略。

但如果训练时不断给 Actor 不同的 `w`：

```
[0.2, 0.1, 0.7]
[0.4, 0.1, 0.5]
[0.3, 0.3, 0.4]
[0.5, 0.2, 0.3]
...
```

Actor 就会学到一族策略：

```
π(a | s, w)
```

不同 `w` 对应不同 trade-off。
 这一族策略就可以近似 Pareto front。

所以你的 Actor 应该这样理解：

```
Actor 不是自己选择单一目标；
Actor 根据输入的 w 在 Pareto 前沿上选择一个折中策略。
```

## 选择更多的偏好
## 方式 A：从偏好库里采样，最稳定
```
def sample_pref_from_library(pref_library, batch_size: int, device: torch.device) -> torch.Tensor:
    prefs = torch.tensor(pref_library, dtype=torch.float32, device=device)
    idx = torch.randint(0, prefs.size(0), (batch_size,), device=device)
    return prefs[idx]
```
优点：
```
稳定，可控，适合你现在这个环境。
```

## 方式 B：Dirichlet 随机采样，覆盖更连续的 Pareto 前沿

```
def sample_pref_dirichlet(batch_size: int, device: torch.device, alpha=(1.0, 0.6, 1.4)) -> torch.Tensor:
    alpha_tensor = torch.tensor(alpha, dtype=torch.float32, device=device)
    dist = torch.distributions.Dirichlet(alpha_tensor)
    return dist.sample((batch_size,))
```

其中：

```
alpha=(1.0, 0.6, 1.4)
```

表示稍微更偏向 `obj`，同时保留 `adv` 和 `coop`。

如果你想更偏突破：

```
alpha=(0.8, 0.4, 2.0)
```

如果你想更均衡：

```
alpha=(1.0, 1.0, 1.0)
```

比较稳的做法是：
```
70% 从偏好库采样
30% 从 Dirichlet 连续采样
```
代码：
```
def sample_preferences(
    batch_size: int,
    device: torch.device,
    pref_library,
    library_prob: float = 0.7,
) -> torch.Tensor:
    if torch.rand(1).item() < library_prob:
        return sample_pref_from_library(pref_library, batch_size, device)

    return sample_pref_dirichlet(batch_size, device, alpha=(1.0, 0.6, 1.4))
```

这样既能保证训练稳定，又能覆盖更多 Pareto trade-off。
